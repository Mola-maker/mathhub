# Self-hosted fonts — sources & licenses

## DINish-var.woff2 (family: "DINish")
- Source: animejs.com site assets; upstream: https://github.com/playbeing/dinish
- License: SIL Open Font License 1.1 — free for commercial use, embedding,
  and redistribution. Derived from Altinn-DIN / Datto D-DIN (also OFL).
- Variable axes (verified via fontTools): wght 300–900 (default 400),
  wdth 75–125 (default 100), slnt −12–0.
- Latin-only — CJK text must fall through the font stack
  (PingFang SC / Microsoft YaHei).

## IoskeleyMonoNL-Regular.woff2 / IoskeleyMonoNL-Italic.woff2
  (family: "Ioskeley Mono NL")
- Source: animejs.com site assets; upstream: https://github.com/ahatem/IoskeleyMono
- License: an Iosevka custom build; Iosevka is SIL OFL 1.1 and derivatives
  remain OFL — free for commercial use, embedding, and redistribution.
  Open alternative to the COMMERCIAL Berkeley Mono (US Graphics) —
  Berkeley Mono files themselves were deliberately NOT copied.
- NL = ligatures disabled variant (web-safe for code display).

## Not copied (license-unsafe or unclear)
- BerkeleyMono-*.woff2 — commercial (US Graphics TX-02).
- Digital-7MonoItalic.woff2 — license unclear.
- DINishExpanded-Bold.ttf — redundant; the variable woff2 covers
  wdth 125 + wght 700.
